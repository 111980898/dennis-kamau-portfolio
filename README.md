# Dennis Kamau — Developer / IT Portfolio

A responsive, navigable developer / IT portfolio inspired by the supplied mobile reference recording.

## Included
- Smooth section navigation with active navigation state
- Mobile navigation drawer
- Scroll progress indicator
- Reveal animations and subtle hover/magnetic interactions
- Formal + casual profile photography
- Technical foundation and terminal-style visual
- GitHub project archive link
- Full CV viewer with PDF/DOCX downloads and direct PDF fallback
- Request Proposal button that opens a pre-filled Gmail compose window
- LinkedIn, Instagram, X and GitHub links
- Responsive layout and reduced-motion accessibility support

## Deploy
This is a static site. Upload the contents of this folder to GitHub and connect the repository to Netlify or Vercel. No build command is required.
